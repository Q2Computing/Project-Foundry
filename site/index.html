The loop

generate

An agent proposes

A deterministic grid or Gemini proposes candidate cells: stage counts, drive strengths, tapers. Exploratory and cheap

assess

The oracle judges

GitHub Actions re-measures the baseline and every candidate in one ngspice bench on the open sky130 PDK, then decides who wins

anchor

Provenance is recorded

Each verified, unique win is hashed and prepared for an on-chain record. The hash commits the design, the netlist stays private

Why it holds up

Same transistors

Candidates use only the nfet_01v8 and pfet_01v8_hvt units the foundry buffers are built from. A win is a better arrangement, not a faster device

Independent judge

The generator never grades its own work. A clean CI runner fetches the pinned PDK and reproduces every number bit for bit

Disclosure safe

Only a hash and a coarse label reach the public record. Anyone with the netlist can verify, no one else can read it

Scope, stated plainly: these are deck-clean, SPICE-characterized results on the open PDK, not foundry-qualified cells. Area is a transistor-width proxy, not laid-out area. Layout, DRC and LVS are the next step
